# PARALEL (Pasar Aset Lelang)

## Summary
Paralel adalah prototype On-chain Auction Market yang mengadopsi desain **Web3 + RWA** (aset fisik) menggunakan **Arbitrum** untuk pasar Indonesia. Dana bidder tetap non-custodial; smart contract adalah sumber kebenaran untuk bid, stake, peringkat, dan dana.

## Stack
Solidity + Foundry · Arbitrum (testnet: Arbitrum Sepolia) · Next.js (TypeScript) · wagmi + viem · PostgreSQL (Neon) + Drizzle · Cloudflare Workers (keeper, indexer, bot Telegram) · next-intl (EN default, ID terjemahan).
